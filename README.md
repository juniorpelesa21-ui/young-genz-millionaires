# Young GenZ Millionaires — starter website

This is a front-end starter with a lightweight Node.js static server.

## Run locally
1. Install Node.js 18 or newer.
2. Run `npm start`.
3. Open `http://localhost:3000`.

## Deploy on Render
Create a **Web Service** connected to this GitHub repository:
- Runtime: Node
- Build command: `npm install` (or leave empty)
- Start command: `npm start`
- Plan: Free

## Important before accepting members or money
This starter is a public information/registration-interest page only. It does not create accounts, store registrations, verify payments, provide a member dashboard, or process M-Pesa payments.
